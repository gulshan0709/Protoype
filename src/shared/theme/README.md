# Reference theme

The app uses the theme from `Vizenta_Four_Industry_Interactive_UI_Dev_Package_2026-09-21/dist/education-v2/styles.css`. Corporate, Retail/Warehouse and Manufacturing declare the same theme variables.

| Panel | `#ffffff` | `#102a43` |
| Sidebar | `#0d385d` | `#123f65` |
| Text | `#132940` | `#edf6ff` |
| Muted text | `#5d7388` | `#a5bbcd` |
| Border | `#cbdce9` | `#315874` |

Shared components also follow the source's 12 px panel corners, 8 px buttons, pill statuses, 98 px joined KPI cells, compact table rows and Inter typography. The reference wordmark is bundled unchanged in `assets/brand/`. Mobile keeps the universal app's touch navigation while using the same semantic theme.
